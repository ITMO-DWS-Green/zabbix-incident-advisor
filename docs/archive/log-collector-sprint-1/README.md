# Архив: log-collector, спринт 1

До 26.10.2026 команда делала **log-collector** — свою систему мониторинга: генератор логов и метрик, приём, хранилище, правила и ML, свой веб-интерфейс, чат инцидента. Затем решили делать расширение Zabbix ([D-004](../../architecture/decisions.md)), а репозиторий [log-collector](https://github.com/ITMO-DWS-Green/log-collector) перевели в архив.

Здесь — основные страницы базы знаний на конец спринта 1, без изменений. Нужны, чтобы показать на защите, что изменилось и почему, и не потерять согласованные с заказчиком формулировки.
