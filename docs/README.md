# База знаний Incident advisor

**Incident advisor** (репозиторий `zabbix-incident-advisor`) — расширение Zabbix 7.0 для разбора инцидентов. Когда срабатывает триггер, оно находит, с какого сервиса всё началось, подкрепляет вывод метриками и строками логов, пишет разбор в проблему Zabbix и отправляет его ответственной команде.

Здесь всё, что команда знает о продукте, требованиях и договорённостях. Правим через Pull Request, как и код.
